## 🚀 HOW TO GET STARTED

### Option 1: Run Everything Locally (5 minutes)
```bash
# Terminal 1: Start all services
cd d:\Project\ITQuty\imsquty
.\deploy-core.ps1

# Terminal 2: Start API Gateway
cd d:\Project\ITQuty\imsquty\api-gateway
npm run dev

# Terminal 3: Start Web App
cd d:\Project\ITQuty\imsquty\frontend\web-app
npm run dev

# Terminal 4: Start Admin Panel
cd d:\Project\ITQuty\imsquty\frontend\admin-panel
npm run dev

# Visit:
# - Web App: http://localhost:5173 (or 3000)
# - Admin Panel: http://localhost:5174 (or 3001)
# - API Gateway: http://localhost:8000
```
