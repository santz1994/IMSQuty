## 💡 BEST PRACTICES

### When Adding New Documentation
1. **Location**: Always use `/docs` folder
2. **Naming**: Use descriptive names (e.g., `SERVICE_NAME_PURPOSE.md`)
3. **Indexing**: Update this file with new document
4. **Links**: Use relative links to other docs
5. **Status**: Mark with date and completion status

### When Updating Existing Documentation
1. **Date**: Update "Last Updated" date
2. **Status**: Update completion status
3. **Index**: Update master index if title/purpose changes
4. **Cleanup**: Remove outdated information

### When Removing Documentation
1. **Verify**: Ensure no other docs reference it
2. **Archive**: Consider moving to archive folder instead of deleting
3. **Index**: Remove from this master index
4. **Links**: Update any broken links
